# OSRS_Market_Watch

*This project is intended to be a market alert system for OSRS. The API is hosted on a server and pulls the GE market statisics every 5 minutes, gathering updates to prices. This data is later extracted into training datasets and will be fed into a linear regression ML model to predict market changes and alert when opportunities to flip arise.*

## Tech Stack: 
[Frontend] - Angular, Material
[API] - ASP.NET v10
[DB] - Sqlite3
[ML] - Python, Tensorflow, Numpy, Pandas, SK-Learn
